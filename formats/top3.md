# Format 5 — TOP 3

**Promise:** "Top 3 [AWP clutches at Majors / Valorant aces / Baron steals]". Countdown, #1 last.
**Why:** search-friendly titles ("Top 3 … [game]"), and every item is reusable later in long 16:9 compilations
(where YouTube ad revenue is much higher than Shorts).
Series tag: `TOP 3 · #N`. Length 75–90 s → keep each item ≈ 20 s.

## Section plan
| # | section | content |
|---|---|---|
| 1 | `cold_open` | `title3d` = "TOP 3", `punch_text` = the topic ("AWP CLUTCHES") |
| 2 | `cards` | kicker "#3", headline = player, sub = event · year |
| 3 | `radar` (own scene) | item #3, condensed: 3–4 lines, kills only |
| 4 | `cards` | "#2" |
| 5 | `radar` | item #2 |
| 6 | `cards` | "#1" |
| 7 | `radar` | item #1 (the longest, with stats) |
| 8 | `cards` | outro "YOUR #1? ▼" |

## Rules
- Each radar item needs its own `map` block (different maps are fine). Skip `context` to stay short.
- Order by a stated criterion (stakes, difficulty, prize) and say it in the cold open.
- Long-form: render each item alone (same spec, one radar) and assemble a 16:9 compilation later.
